🟢 STEP 1 — Scoprire la directory maps
Obiettivo

Partire dal progetto e riuscire a individuare:

maps/
Tasks
 Individuare il path della cartella maps
 Verificare che esista
 Verificare che sia una directory
Test

Il programma deve riuscire a dirti:

maps directory found ✓
🟢 STEP 2 — Scoprire i livelli

Dalla cartella:

maps/
├── easy/
├── medium/
├── hard/
└── challenger/

devi ottenere:

easy
medium
hard
challenger
Tasks
 Iterare sulle directory dentro maps
 Ignorare eventuali file
 Salvare il nome della directory
 Creare il dictionary principale
Risultato concettuale

    "easy": ...,
    "medium": ...,
    "hard": ...,
    "challenger": ...
}

⚠️ Non devi ancora parsare nessun file.
